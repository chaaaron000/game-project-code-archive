# Game Project Code Archive

게임 프로그래머 포트폴리오와 면접 준비를 위해, 여러 프로젝트에서 직접 설계·구현했거나 의미 있게 수정한 코드와 개발 워크플로를 선별해 정리한 아카이브입니다.

> 이 저장소는 원본 Unity 프로젝트의 완전한 복제본이 아닙니다. 포트폴리오에서 설명할 가치가 있는 코드와 구조만 선별하며, 팀 프로젝트에서는 작성자와 기여 범위를 구분합니다.

## Contribution labels

- **CORE** — 직접 설계하거나 주도적으로 구현한 핵심 코드
- **MODIFIED** — 다른 팀원의 기존 코드에 기능을 추가하거나 구조를 수정한 코드
- **REFERENCE** — 핵심 코드의 맥락 이해에 필요한 보조 자료. 본인 구현으로 주장하지 않음
- **WORKFLOW** — 코드보다 개발 과정·자동화·검증 방식 자체가 핵심인 사례

## Authorship policy

팀 프로젝트의 현재 파일만 보고 소유권을 추정하지 않습니다. 가능하면 Git commit 작성자와 변경 이력을 확인해 `CORE`, `MODIFIED`, `REFERENCE`로 구분합니다. 다른 팀원이 주도적으로 구현한 시스템은 포트폴리오 기여로 표기하지 않습니다.

## Third-party / paid assets

유료 에셋, 제3자 소스 코드, 바이너리 및 재배포 권한이 불명확한 파일은 이 저장소에 포함하지 않습니다. 특히 Visual Novel Dev에서 사용하는 Naninovel의 엔진 소스, 패키지, Language Server 번들은 포함하지 않고, 이를 활용해 구축한 개발·검증 워크플로만 설명합니다.
